Tabelas em telas pequena

Em telas pequenas, as tabelas podem ser difíceis de ler. Para melhorar a legibilidade, podemos usar CSS para tornar as tabelas responsivas. Isso pode ser feito usando a propriedade display: block; para transformar a tabela em um bloco e permitir que ela role horizontalmente.
